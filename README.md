# LLMCliches

LLMCliches is a Vale style that flags phrases and rhetorical patterns commonly
associated with generic LLM-generated prose. It is a writing aid, not an AI
detector: every alert requires editorial judgment, and an alert does not prove
that text was generated by a model.

The initial rules cover AI-associated vocabulary, canned significance,
didactic hedging, negative parallelism, promotional language, vague
attribution, superficial participle tails, and chatbot artifacts. The rule set
is informed by Wikipedia's [Signs of AI writing][wiki] guide and inspired by
Simon Willison's [LLM cliché highlighter][highlighter]. The implementation is
independent and designed for Vale's regular-expression engine.

## Install

Vale 3.19.0 or later is required. Until a release is available, build and use a
local package:

```console
make bootstrap build
```

```ini
StylesPath = styles
MinAlertLevel = suggestion
Packages = /absolute/path/to/LLMCliches.zip

[*.{md,mdx}]
BasedOnStyles = LLMCliches
```

Run `vale sync`, then lint your prose with `vale path/to/file.md`.

## Develop

```console
make test
```

Rules and their tests live together in [`package/LLMCliches`](package/LLMCliches).
Prefer precise, explainable checks over broad word bans. New rules should
include positive matches, accepted examples, case handling, and Markdown code
exclusions where relevant.
